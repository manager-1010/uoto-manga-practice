# 魚豊漫畫閱讀網站

十六頁漫畫分鏡網站，保留原有翻頁、動畫、五詞互動及原作圖片。第一次開啟預設繁體中文，可在頁首切換英文和日文；瀏覽器會記住上一次的語言選擇。

五位《100M》人物：富樫、小宮、仁神、海棠、財津。以黑白原作、少量朱紅跑道與軌道幾何，以及漫畫氣泡組成頁面。

繁中標題用 Noto Serif TC 900；內文及對白用昭源宋體（Chiron Sung HK）400／700。日文為 Noto Serif JP 及 Klee One，英文為 Bangers 及 Comic Neue。網頁字體及授權隨網站自架。

正式網址：https://uoto-manga-practice.pages.dev/

## 日後修改

三語文字的原始資料在 `content/translations.json`。以穩定文字ID對應頁面；保留每個語言的相同ID。`content/translations.js` 是產生檔，不直接修改。漫畫圖片內的原有文字保留。

最後兩頁的購買網址也在同檔的 `purchaseLinks`：繁中連香港「紙本分格」書店商品頁，日文連講談社／小學館官方商品頁，英文連 Simon & Schuster／Seven Seas 官方商品頁。未設定相應語言網址時回退至該書的日文官方頁。保留原有按鈕文字及排版。

2026-10-21 查證：英文《100 Meters Vol. 1》由 Nakama Press 出版、Simon & Schuster 發行，官方頁目前標示2027-02-16出版；這個連結不代表已上市。其餘網址及版本資料見 `purchaseLinks` 中的實際官方商品頁。

執行 `npm run check` 及 `npm run build` 後，公開產物在 `dist/`。建置採乾淨暫存目錄，上一份產物保留在本機 `.build-history/`，不把舊檔混入新版本。建置不需要新增套件。

Cloudflare Pages沿用既有GitHub連接、`main`正式分支及原本建置設定。工作分支先產生預覽，合併後才更新正式網站。

## 本機視覺編輯

這個公開倉庫只保存閱讀網站所需原始碼。本機完整第9版另外保留原有私人編輯器及人工儲存資料，不把編輯介面、寫入服務、`page6.json` 或私人素材草稿加入此網站產物。

新增中日文是網站閱讀企劃的譯寫；引句翻譯不代表官方版本台詞。日語內容尚未由母語校對者審讀。

## 第19版互動漫畫

沿用16頁三語、原圖、字體、購買網址與翻頁。開場人物突破書框；第3頁短跑步結束後，第4頁問題逐字出場。第7至10頁有少量完整外側墨線及單圖短動作；第9、10頁重點短句按先後出場，第12頁文字靜態。

背景音樂與短音效預設關閉，點開音效後才播放；主題曲細聲循環，翻頁與轉語言不會重播，關閉時一起停。音樂的官方影片、日文原名、詞曲及錄音署名在來源欄。音檔沿用本次由使用者提供的MP3。

`npm run check` 驗證17個JavaScript檔案，`npm run build` 產生白名單公開檔案。私人編輯器、文件與測試不會打入dist。
